Android 첫 무료 공개판

Android 첫 무료 공개판에는 인앱결제·구독 및 Google Drive 자동 백업 연결이 없습니다. 반려동물 두 마리까지의 기록, 영수증 인식, 가계부, 청구 상태, 일정·알림, 수동 ZIP 백업·복원을 제공합니다. Pro 확장 기능은 이 버전에 포함되지 않습니다. 아래의 Pro·Apple 결제 관련 내용은 해당 기능을 제공하는 iOS 버전에 적용됩니다.

기기에 저장하는 기록

회원가입과 개발자 서버 없이 사용자가 입력한 기록을 기기에 저장합니다. 개발자는 사용자의 기록·사진·백업에 접근할 수 없습니다.

  • 반려동물 이름·종류·생일·사진·동물등록번호 등 사용자가 입력한 정보
  • 병원 방문·지출·보험 정보·청구 상태·지급액
  • 영수증·세부내역서·직접 추가한 사진
  • 예방 일정·투약·체중 기록, 건강 메모·검사 결과·직접 입력한 기준 범위, 진료비 메모와 앱 설정

동물등록번호는 소유자와 연결될 수 있는 정보로 다룹니다. 사진에는 보호자 이름·연락처·카드번호 일부가 포함될 수 있으므로 공유 전에 확인해 주세요.

영수증 인식과 SDK 진단 정보

영수증은 Google ML Kit으로 기기 안에서 읽습니다. 앱은 인식 원문을 저장하거나 개발자에게 전송하지 않습니다. 저장 버튼을 누르면 사용자가 확인한 금액·날짜·병원·세부 항목과 사진을 기기에 보관합니다.

Google의 Android·iOS SDK 공개 내용에 따르면 ML Kit은 기기·앱 정보, 설치 식별자, 사용·성능·오류 지표를 Google에 전송합니다. 이 SDK의 지표 전송과 영수증 사진·인식 글자의 기기 안 처리를 구분합니다. Android 데이터 공개와 iOS 데이터 공개를 참고할 수 있습니다.

예시 영수증 체험

앱에 포함된 합성 영수증으로 확인 화면과 가계부 미리보기를 제공합니다. 체험의 입력·제안값을 기록 DB나 사진 보관함에 저장하거나 개발자에게 전송하지 않습니다. 처리가 필요한 파일은 체험 전용 임시 폴더만 사용하고 종료·다음 실행 때 정리합니다. 기기 OCR을 사용하는 체험에도 위 ML Kit 진단 정보 안내가 적용됩니다.

영수증 개인정보 가리기

사용자가 고른 구역을 기기 안에서 단색으로 덮은 이미지 사본을 만듭니다. 글자 줄에서 고르기에 사용한 인식 줄과 구역 좌표는 보관하지 않습니다. 자동으로 모든 개인정보를 찾지는 못하므로 저장 전에 직접 확인해 주세요. 원본 사진과 가린 사본은 앱에 함께 남으며 사진을 포함하는 백업에도 함께 들어갑니다. 가리기는 원본을 삭제하는 기능이 아닙니다.

사용자가 선택한 가린 사본만 공유하거나 청구 서류 팩에 넣을 수 있습니다. 청구 팩은 사진마다 선택하며 기본값은 원본입니다. 보험사가 원본 확인을 요청할 수 있습니다. 이미 다른 앱에 공유한 사진·파일은 앱에서 되돌리거나 지울 수 없습니다.

사용자가 선택하는 백업과 공유

iOS 및 Android 첫 무료 공개판은 사용자가 직접 ZIP 파일을 내보내고 가져오는 백업·복원을 제공합니다. iCloud Drive 연결은 준비 중이며 현재 배포 빌드에서는 사용할 수 없습니다. 개발자가 운영하는 저장소로 백업하지 않습니다. 사용자가 ZIP을 파일 앱이나 다른 서비스로 저장한 경우 해당 서비스의 정책이 적용됩니다.

PDF·CSV·ZIP·가린 사진 사본은 사용자가 공유 화면에서 선택한 앱으로만 전달합니다. CSV에는 선택한 지출과 메모를 넣고 사진·인식 원문은 넣지 않습니다. ZIP은 암호화된 백업이 아니며 원본과 가린 사본을 함께 포함할 수 있으므로 파일 보관·공유 상대를 직접 확인해 주세요. 클라우드·공유 서비스의 보관 지역은 해당 서비스의 정책에 따르며 국내 밖일 수 있습니다.

기기 기본 백업

앱이 올리는 백업과 별개로, 휴대폰 운영체제의 기본 백업이 켜져 있으면 기록이 사용자 본인 계정의 기기 백업에도 들어갈 수 있습니다. iPhone은 iCloud 백업이나 컴퓨터 백업에 기록과 사진이 포함될 수 있고, Android는 구글 계정의 기기 백업에 기록이 포함될 수 있습니다(사진 제외). 그래서 앱을 지운 뒤 다시 설치하거나 새 휴대폰으로 옮기면 기록이 돌아올 수 있습니다. 이 백업은 Apple·Google이 사용자 계정에 보관하며 개발자는 접근할 수 없습니다. 원하지 않으면 iPhone은 설정의 iCloud 백업(컴퓨터 백업은 백업을 만드는 컴퓨터)에서, Android는 휴대폰 설정의 백업에서 끌 수 있습니다. 여러 장 등록 대기열과 앱 잠금 설정은 Android 기기 백업에서 제외합니다.

공유 대상 앱이 파일을 읽을 수 있도록 공유를 요청한 임시 사본은 마지막 공유 종료 뒤24시간 동안 기기에 보관합니다. 이후 앱 실행 때 정리하며 공유 중인 파일은 정리에서 제외합니다. 공유 전 그만두면 새로 만든 사본은 정리하고, 이미 생성한 CSV는 생성 시각을 유지합니다. 백업 공유에는 ZIP만 남기고 작업 중의 DB·사진 사본은 정리합니다. 이 보관은 원본 기록이나 다른 앱이 받은 파일을 삭제하지 않습니다.

보장 사용 현황

사용자가 넣은 보험 조건과 지출·청구 기록으로 기기 안에서 합계와 참고값을 계산합니다. 이 계산을 위해 데이터를 외부에 전송하지 않습니다. 실제 지급액은 보험사가 정합니다.

여러 장 등록과 앱 잠금

여러 장 등록에서 아직 확인하지 않은 사진 사본과 남은 순서는 기기에 임시 보관합니다. 인식 원문은 대기열에도 보관하지 않으며 대기열은 앱의 백업 ZIP과 Android 자동 백업에 넣지 않습니다. 그만두면 대기열 사본만 지우고 갤러리 원본과 저장한 기록은 그대로 둡니다.

앱 잠금은 운영체제의 생체 인증 또는 기기 잠금 암호를 사용합니다. 앱은 본인 인증 결과만 받고 지문·얼굴 원본이나 기기 암호를 받거나 보관하지 않습니다. 잠금 설정은 기기 전용이며 백업·복원으로 옮기지 않습니다. Pro가 끝나도 켜 둔 잠금은 유지됩니다. 앱 잠금이 이미 내보낸 PDF·CSV·ZIP에 암호를 거는 것은 아닙니다.

결제와 수집하지 않는 정보

현재 iOS 버전의 결제는 Apple이 처리하고 앱은 구매 상태를 기기에 저장합니다. 앱은 결제 카드 번호나 계좌 정보를 받지 않습니다. 위치·연락처·광고 식별자를 받는 기능, 개발자용 사용 분석·크래시 수집 SDK는 넣지 않습니다. 보호자 본인의 건강정보를 입력받는 서비스가 아닙니다.

보관과 삭제

기록은 사용자가 기기에 보관합니다. 개별 기록을 삭제하면 목록에서 제거하며 5초 되돌리기를 제공합니다. 앱의 ‘모든 기록 지우기’와 앱 삭제로 기기 데이터를 지울 수 있습니다. 파일 앱이나 다른 앱에 내보낸 ZIP·PDF·CSV·사진과 운영체제의 기기 백업은 기기 기록 삭제와 별개입니다. 내보낸 파일은 해당 저장 위치에서 직접 삭제할 수 있습니다. 복원 전 보관본은 앱이 안내하는 기간 동안 기기에 남으며 이후 정리합니다.

개발자가 원격에서 사용자의 기기 데이터를 조회·수정·복구할 수 없습니다. 문의할 때 실제 영수증·동물등록번호·카드번호·클라우드 백업 파일을 보내지 않아도 됩니다.

변경 안내

이 앱은 14세 미만 어린이를 대상으로 만들지 않습니다. 가족 공유·계정 등 새로운 기능으로 처리 방식이 달라지면 이 문서를 개정하고 앱과 공개 페이지에 안내합니다.
